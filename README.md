## README

Vincent Chen & Jason Zhang

3D Ballistic Pendulum

AP Physics C, Period 8

This program seeks to simulate a ballistic pendulum with one degree (polar angle) and two degrees (a polar and 
azimuthal angle) of freedom, with motion, displayed in 3 dimensions. The user will be allowed to change various 
inputs (as mentioned below), and, upon clicking start, will see their inputs affect the pendulum's motion!

To use this program, simply put in inputs for the bullet mass, bullet speed, ball mass, and, for 1
degree of freedom, the length of the pendulum, or for 2 degrees, the angle of the bullet to the 
initial motion of the pendulum. This program makes use of the assumption of a perfectly 
massless, rigid rod, and allows for dampening of motion over time in the 2 degrees of freedom case. 

The program allows the user to initially select the 1D (1 degree of freedom) or 2D (2 degrees of freedom) options,
and following that, the user can select start/stop to pause the animation, and reset to try new inputs. Then, 
watch as your pendulum launches!
